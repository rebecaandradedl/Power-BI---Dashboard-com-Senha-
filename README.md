# Dashboard de Análise de Campanhas – Power BI

## 📊 Sobre o projeto

Este projeto consiste no desenvolvimento de um dashboard interativo utilizando o **Microsoft Power BI**, com o objetivo de facilitar a visualização e a análise de dados relacionados a campanhas, produtos e investimentos em anúncios.

O dashboard apresenta informações por meio de gráficos, indicadores e filtros interativos, permitindo acompanhar os resultados, comparar valores e identificar oportunidades de melhoria com base nos dados apresentados.

## 🎯 Objetivos

- Organizar e visualizar dados de forma clara e intuitiva.
- Analisar o desempenho de campanhas e produtos.
- Acompanhar valores convertidos e gastos com anúncios.
- Facilitar a comparação de resultados por gerente de campanha.
- Apoiar a tomada de decisões por meio da análise de dados.

## 🛠️ Ferramentas utilizadas

- **Microsoft Power BI:** criação dos dashboards e visualizações.
- **Visualização de dados:** gráficos, indicadores e filtros interativos.

## 📈 Principais funcionalidades

- Relatório geral com indicadores e gráficos.
- Relatório de análise de campanhas do Instagram.
- Comparação de resultados por produtos e gerentes de campanha.
- Visualização de valores convertidos e gastos com anúncios.
- Navegação entre páginas do relatório.
- Tela de acesso com validação de senha.
